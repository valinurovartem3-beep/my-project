# Бот прогнозов на матчи CS2 и Dota 2

Telegram-бот, который берёт расписание и результаты матчей из PandaScore, считает рейтинг каждой команды и выдаёт вероятность победы в предстоящих матчах — по всем турнирам, которые есть в базе.

## Что умеет

**Главное: просто напишите матч.** Например, `NAVI vs Spirit`. Бот сам определит игру и пришлёт три сообщения:
1. **Сводка**: общий прогноз, прогноз по картам (для CS2), самый вероятный счёт и итоговая вероятность — среднее двух прогнозов.
2. **Разбор команд**: рейтинг, форма, последние результаты, личные встречи, ключевые факторы.
3. **Прогноз по картам** (только CS2): пик-бан, шансы на каждой карте, счёт серии, раунды за T и CT.

Понимает разные формулировки: `navi - mouz`, `Natus Vincere против MOUZ`, `spirit vs falcons дота bo3`. Если матч есть в расписании, бот возьмёт его турнир, время и формат. Если нет — посчитает гипотетический матч в формате Bo3, другой формат можно указать: `bo1` или `bo5`. Если обе команды есть и в CS2, и в Dota 2 (например, Spirit), а матча в расписании нет, бот спросит, какую игру разобрать. Подсказать игру можно сразу: `кс` / `cs` или `дота` / `dota`.

Остальные команды:

| Команда | Что делает |
|---|---|
| `/start` | Меню с кнопками |
| `/cs`, `/dota` | Ближайшие матчи с прогнозом; нажмите на матч — подробный разбор |
| `/maps NAVI vs Spirit` | Прогноз по картам CS2: вероятный пик-бан, шансы на каждой карте, счёт серии, раунды за T и CT. Можно добавить `bo1` или `bo5` |
| `/team NAVI` | Карточка команды: рейтинг, место, форма, последние 5 матчей |
| `/top_cs`, `/top_dota` | Рейтинг команд |
| `/stats` | Статистика прогнозов: сколько угадано, точный счёт, честность процентов. Фильтры: `/stats 30`, `/stats кс`, `/stats дота`, `/stats мои` |
| `/subscribe`, `/unsubscribe` | Ежедневная сводка прогнозов в 10:00 МСК |

## Как считается прогноз

1. **Рейтинг Эло.** Бот загружает последние ~1000 завершённых матчей по каждой игре и прогоняет их по порядку. Победа над сильным соперником поднимает рейтинг сильнее, матчи турниров tier S/A весят больше, разгромные счета (2:0) — больше, чем 2:1.
2. **Форма** — доля побед в последних 10 матчах (свежие важнее).
3. **Личные встречи** — последние 5 игр между командами, со сглаживанием, чтобы 1–2 встречи не перевешивали.
4. **Формат.** В Bo1 прогноз прижимается к 50%, в Bo5 фаворит получает небольшую прибавку.

Основной вес у рейтинга, форма и личные встречи лишь слегка его корректируют. Рейтинг пересчитывается каждые 3 часа. Для каждой команды бот указывает уверенность: если о команде мало данных, прогноз помечается как ненадёжный.

На тестовых данных прогноз оказался близок к точности, которая в принципе достижима. На реальных матчах точность будет ниже: модель не знает о заменах в составах, буткемпах и пиках карт.

## Прогноз по картам CS2

В карточке матча CS2 есть кнопка «🗺 Прогноз по картам», то же самое делает команда `/maps`.

**Откуда данные.** Счёт каждой сыгранной карты с разбивкой по половинам (за T и за CT) бот берёт из Liquipedia: турниры уровня S и A за этот и прошлый год, учитываются карты за последние 180 дней.

**Как считается:**
1. У каждой команды есть общий рейтинг по всем сыгранным картам и поправка на каждую отдельную карту. Поправка растёт, только если команда на этой карте стабильно играет лучше или хуже своего обычного уровня. Поэтому одна-две случайные победы не делают карту «коронной».
2. Пик-бан предсказывается так: каждая команда банит карту, где ей хуже всего, и выбирает ту, где у неё самый большой перевес и есть опыт. Это догадка: настоящие пики зависят от подготовки к сопернику.
3. Из шансов на ожидаемых картах считается вероятность каждого счёта серии (2:0, 2:1 и т. д.).

На тестовых данных поправки на карты заметно улучшили точность по сравнению с одним общим рейтингом.

**Ограничения:**
- Liquipedia строго ограничивает частоту запросов. Бот делает не больше одного запроса в 5 секунд, обновляет данные раз в 6 часов и скачивает заново только изменившиеся страницы. Поэтому **первая загрузка занимает примерно 5–10 минут**, всё это время остальные функции бота работают как обычно. Потом данные сохраняются в `liquipedia_cache.json`, и после перезапуска бот сразу их использует.
- Не уменьшайте паузу между запросами: при слишком частых запросах Liquipedia временно блокирует IP.
- По правилам Liquipedia данные распространяются по лицензии CC-BY-SA, поэтому бот указывает источник под каждым прогнозом.
- Команды, которые не играли турниры уровня S и A, в статистике карт не появятся. Их можно добавить настройкой `LIQUIPEDIA_TIERS=S,A,B`, но первая загрузка тогда будет дольше.

## Статистика прогнозов

Бот сам ведёт журнал своих прогнозов и проверяет, сколько угадал.

**Как это работает:**
1. Каждые 30 минут бот записывает прогнозы на все матчи CS2 и Dota 2 ближайших суток. Матчи, которые вы спрашивали сами, тоже записываются и помечаются как «ваши».
2. Пока матч не начался, прогноз обновляется на свежих данных. **С началом матча он замораживается**, поэтому подправить его задним числом нельзя и статистика честная.
3. Раз в час бот забирает результаты из PandaScore и отмечает, угадан ли прогноз. Отменённые матчи и технические поражения в статистику не идут.

**Что показывает `/stats`:**
- процент угаданных победителей отдельно для итогового прогноза, общего прогноза и прогноза по картам: так видно, какой из них работает лучше;
- как часто угадан точный счёт серии;
- **честность процентов**: из матчей, где бот давал около 65%, должно угадываться примерно 65%. Если угадывается заметно меньше, модель переоценивает себя;
- индекс Брайера — одно число для общей оценки точности: у подбрасывания монетки 0,250, чем меньше, тем лучше;
- последние 10 матчей: ✅ / ❌, а 🎯 — угадан точный счёт.

В ежедневную сводку (`/subscribe`) добавлена строка, сколько прогнозов угадано за прошедшие сутки.

Журнал хранится в файле `predictions.db` в папке бота. Не удаляйте его при обновлении бота, иначе статистика начнётся заново. Делать выводы о точности стоит после 50–100 матчей: на десятке матчей проценты сильно зависят от случая.

## Установка

Нужен Python 3.10 или новее.

1. **Токен бота.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **Токен PandaScore.** Зарегистрируйтесь на [pandascore.co](https://app.pandascore.co) и скопируйте токен из Dashboard. Бесплатного тарифа хватает (около 1000 запросов в час).
3. **Контакт для Liquipedia.** Впишите в `LIQUIPEDIA_CONTACT` свою почту или ник в Telegram, так Liquipedia понимает, кто к ней обращается. Без этого прогноз по картам отключится, остальное будет работать.
4. **Установка и запуск:**

```bash
cd esports_bot
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # Windows: copy .env.example .env
# откройте .env и вставьте оба токена
python bot.py
```

При первом запуске бот примерно минуту скачивает историю матчей, после этого можно писать ему `/start`.

## Чтобы бот работал круглосуточно

Бот работает, пока запущен `python bot.py`. Чтобы он не зависел от вашего компьютера, его можно разместить на любом VPS (например, за 200–400 ₽ в месяц) и запускать как службу через systemd:

```ini
# /etc/systemd/system/esports-bot.service
[Unit]
Description=Esports prediction bot
After=network.target

[Service]
WorkingDirectory=/opt/esports_bot
ExecStart=/opt/esports_bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now esports-bot
```

## Файлы

- `bot.py` — команды Telegram, кнопки, ежедневная сводка
- `model.py` — модель прогнозов (Эло + форма + личные встречи)
- `pandascore.py` — загрузка данных из PandaScore
- `liquipedia.py` — загрузка и разбор счёта по картам из Liquipedia
- `mapmodel.py` — модель прогноза по картам и пик-бана
- `liquipedia_cache.json` — создаётся автоматически, сохранённые данные о картах
- `tracker.py` — журнал прогнозов и подсчёт статистики
- `predictions.db` — создаётся автоматически, журнал прогнозов (не удаляйте)
- `subscribers.json` — создаётся автоматически, список подписчиков сводки

> Прогнозы — статистическая оценка, а не гарантия результата.
